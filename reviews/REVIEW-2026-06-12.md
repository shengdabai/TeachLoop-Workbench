# TeachLoop Review - 2026-06-12

## Scope

Reviewed the local static learning product, teach workspace structure, installation paths, browser behavior, and mobile responsiveness.

## Findings

1. Fixed: mobile horizontal overflow.
   - Evidence before fix: 390px viewport produced 696px body width.
   - Root cause: grid children and table container kept default minimum content width.
   - Fix: added `min-width: 0` to shell/panels and constrained `.plan-table` with internal horizontal scrolling.
   - Evidence after fix: 390px viewport produced 390px body width; table scrolls inside its own container.

2. Fixed: favicon 404 console noise.
   - Root cause: browser requested `/favicon.ico`.
   - Fix: added inline SVG favicon data URL in `index.html`.
   - Evidence after fix: Playwright interaction run returned `errors: []`.

## Known Limits

- The app is intentionally local-only and stores state in browser `localStorage`.
- It does not automatically fetch or summarize web resources.
- It does not write exported markdown back to disk from the browser; the user copies or asks an agent to commit the record.
